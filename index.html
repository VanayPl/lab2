Про мене

Вмотивований розробник-початківець із досвідом написання базових алгоритмів, роботи з Git та створення вебінтерфейсів. Прагну розвиватися в напрямку сучасної фронтенд-розробки.

Освіта та практичний досвід

  • Поглиблене вивчення інформатики в ліцеї (2022 — 2026): 4 роки системного вивчення алгоритмів, структур даних та основ комп'ютерних наук.
  • Лабораторний практикум із веброзробки (2026): створення семантичної структури вебсторінок на чистому HTML5 та перенесення інтерфейсу на компонентну архітектуру React за допомогою Vite.

Технічні навички

  • HTML5, базові концепції веброзробки
  • React.js (створення базових компонентів, робота з Vite)
  • Система контролю версій Git та сервіс GitHub
  • Алгоритмічне мислення та комп'ютерна логіка
